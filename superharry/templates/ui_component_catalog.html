Components

Load components.css, add class="sh" to the container, then copy the HTML from an example. The SVG symbols in this page provide the outline icons.

Actions

Use one primary action per area. Use quiet actions for composer tools and danger styling for destructive commands.

HTML
<button class="sh-button sh-button-primary" type="submit">
  Save changes
</button>
<button class="sh-button sh-button-quiet" type="button">
  Attach files
</button>

Status and feedback

Keep the status in text. Use an alert for a new error near the control that needs attention.

ScheduledCompletedNeeds user inputCanceled

Choose a PNG or JPEG and try again.

HTML
<span class="sh-status sh-status-warning">
  Needs user input
</span>
<p class="sh-notice sh-notice-error" role="alert">
  Choose a PNG or JPEG and try again.
</p>

New chat and memory

Start with memory unchecked. In an existing chat, show the current setting as text.

HTML
<label class="sh-check">
  <input type="checkbox" name="use_memory">
  Use saved memories in this conversation
</label>

Form fields

Keep instructions and errors next to their field. Let labels wrap at narrow widths.

HTML

  Username
  <input name="username" aria-describedby="username-help">
  <small id="username-help">Use letters, numbers and underscores.</small>
</label>
