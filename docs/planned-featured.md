# Planned Features

Use this file to capture feature ideas before any refinement. A short description is enough. Copy the template below for each idea and add it under **Feature ideas**. Check **Implemented** once the feature is implemented.

Agents may use this file or act on its entries only when the user explicitly asks them to. An unchecked box records implementation status only and grants no authorization to plan, refine, or implement the feature.

## Template

```markdown
### Short feature name

- [ ] Implemented

**Idea**

Describe what you want the feature to do in one or two sentences.
```
