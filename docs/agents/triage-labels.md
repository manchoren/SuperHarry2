# Triage labels

The canonical role and GitHub label strings are identical.

| Role and label | Meaning |
|---|---|
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The maintainer is waiting for more information from the reporter. |
| `ready-for-agent` | An agent can implement the fully specified issue. |
| `ready-for-human` | The issue requires human implementation. |
| `wontfix` | The maintainer declined the issue. |
