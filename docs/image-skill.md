# Image skill

The repository-managed `image` skill provides deterministic PNG and JPEG inspection, resizing, cropping, and conversion. Its `SKILL.md` describes the supported JSON operations. The worker uses the pinned Pillow 13.0.0 distribution (MIT-CMU); it is installed at image build time and is available without direct network access during execution. Only explicitly selected conversation files are copied into the disposable sandbox. Generated files use the normal bounded output and owner-scoped download flow.

The initial implementation accepts one still PNG or JPEG at a time, with at most four million pixels and an input side no longer than 8192 pixels. Output dimensions are limited to 4096 pixels per side and four million pixels, in addition to the worker's configured output byte limit. Orientation is applied. Exported files do not retain the original metadata; JPEG export flattens transparency onto white. Animated images and other formats are rejected. `info` reports format, mode, and dimensions; it does not describe depicted content, perform OCR, or generate images. Those tasks require a separate compatible capability and must not be claimed as completed by this skill.

On 2026-11-26 the team reviewed the public [AgentPMT image-editor skill](https://github.com/AgentPMT/agent-skills/blob/main/skills/image-editor/SKILL.md), which targets an external service and credits, and the [OpenBotX Pillow skill](https://github.com/openbotx/openbotx/blob/main/openbotx/skills/pillow/SKILL.md), which describes a broader arbitrary-code workflow. Neither was copied: this project needs a small, fixed local entrypoint compatible with its network-isolated worker. The implementation follows the [Pillow image API](https://pillow.readthedocs.io/en/stable/reference/Image.html) and preserves the dependency's installed license metadata.

The tests use synthetic files. They verify actual dimensions and formats for the supported operations, metadata removal, transparency handling, orientation, limits, errors, downloads, and original preservation. These checks do not establish visual understanding or prove every image decoder safe.
